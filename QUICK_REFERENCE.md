## ⌨️ Command Shortcuts

### Root (Monorepo)
```bash
npm run install-all    # Install deps for root + hospital_web + donor_app
npm start              # Launch BOTH apps concurrently (web:3000, expo:8081)
```

### Hospital Web (`cd hospital_web`)
```bash
npm start              # React dev server (port 3000)
npm run build          # Production build (build/)
npm run setup          # Runs scripts/setup.js (if exists)
```

### Donor App (`cd donor_app`)
```bash
npx expo start         # Expo dev server (port 8081)
npx expo start -c      # Clear Metro cache
npx expo run:ios       # Build & run iOS simulator
npx expo run:android   # Build & run Android emulator
npx expo install <pkg> # Install Expo-compatible packages
eas build              # EAS Build for store binaries
```

### Supabase CLI
```bash
supabase login
supabase link --project-ref hqdiqjswknukqyghtgsa
supabase functions deploy send-blood-alert
supabase db pull       # Pull schema changes
supabase gen types typescript --project-id hqdiqjswknukqyghtgsa > donor_app/types/supabase.ts
```

## 🗄️ Database Verification

### Check Hospital Role
```sql
SELECT role FROM profiles WHERE user_id = 'your-user-uuid';
-- Should return 'hospital' or 'donor' or 'admin'
```

### Verify Hospital Verification
```sql
SELECT name, is_verified FROM hospitals WHERE user_id = 'your-user-uuid';
-- is_verified must be TRUE for SMS alerts
```

### Check Realtime Enabled
```sql
-- In Supabase Dashboard → Database → Replication
-- These tables must show "Enabled":
-- blood_requests, donor_responses, donors
```

### Test RLS (Run as Authenticated User)
```sql
SET ROLE authenticated;
SET request.jwt.claims = '{"sub": "donor-user-uuid"}';
SELECT * FROM donors;  -- Should return only own record

SET request.jwt.claims = '{"sub": "hospital-user-uuid"}';
SELECT name, blood_group, city, available FROM donors;  -- Basic info only
SELECT phone FROM donors;  -- Should return NULL (policy)
```

## 🐛 Most Common Fixes (30 Seconds)

| Problem | Fix |
|---------|-----|
| Anonymous auth fails | Enable **Anonymous** provider in Supabase Auth Dashboard |
| Maps white screen | Use `maplibre-gl` + `import 'maplibre-gl/dist/maplibre-gl.css'` |
| Web push not working | Set `REACT_APP_VAPID_PUBLIC_KEY` + allow browser notification permission |
| Mobile push not working | Build dev client (`npx expo run:ios/android`), NOT Expo Go |
| Realtime not syncing | Enable **Replication** for `blood_requests`, `donor_responses`, `donors` |
| Phone not visible | Hospital must be `is_verified=true` + donor must have `confirmed` response |
| Env vars undefined | `.env` must be in `hospital_web/` AND `donor_app/` (not root) |
| TypeScript errors | Run `npx tsc --noEmit` in `donor_app/` |
